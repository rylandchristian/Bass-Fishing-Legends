# 05 — UI

The game draws a **Canvas HUD** (`ABFLHUD`) so you get a tension meter, score, and notifications with no UMG asset.

## What you see

| Element | When |
|---|---|
| Score + fish count | Always, top left |
| Control reminder | Always, top right |
| Cast power bar | While charging |
| “Waiting for a bite…” | Bobber in the water |
| **FISH ON!** + species / weight | Fight started |
| Tension bar (green → yellow → red) | Fighting |
| Reel progress bar | Fighting |
| **Fish caught!** `Name  X.X lb  +N` | Success, ~3 seconds |
| **LINE SNAPPED** | Failure |
| Catch log (last 4) | Bottom left |

Notifications are also pushed from C++ via `ABFLHUD::ShowNotification` and `ABFLGameMode::OnNotification`.

## Creating a UMG tension meter (optional)

When you want a designed widget:

### 1. Widget Blueprint

1. Content Browser → `/Game/UI` → **User Interface → Widget Blueprint** → `WBP_FishingHUD`.
2. Hierarchy:

```
CanvasPanel
├── ScoreText                          (top-left)
├── CaughtText
├── NotificationText                   (center)
├── CastBox  (Vertical Box)
│   ├── CastLabel  "CAST POWER"
│   └── CastBar    Progress Bar
└── FightBox (Vertical Box, hidden by default)
    ├── FishOnText  "FISH ON!"
    ├── SpeciesText
    ├── TensionLabel
    └── TensionBar  Progress Bar
    ├── ReelLabel
    └── ReelBar     Progress Bar
```

3. Style `TensionBar`:
   - Fill Color = green.
   - You will change it in graph by percent.

### 2. Graph

**Event Construct**

```
Get Owning Player Pawn
  → Cast to BFLBoatPawn
    → Get Fishing
      → Bind Event to On Tension Changed  → UpdateTension
      → Bind Event to On Cast Power Changed → UpdateCast
      → Bind Event to On State Changed → UpdateState
Get BFL Game Mode
  → Bind Event to On Fish Caught → ShowCatch
  → Bind Event to On Notification → ShowNote
```

**UpdateTension (Tension, ReelProgress)**

```
Set Percent (TensionBar, Tension)
Set Percent (ReelBar, ReelProgress)
Branch Tension > 0.78
  True  → Set Fill Color and Opacity (red)
  False → Branch Tension > 0.55
            True  → yellow
            False → green
```

**UpdateState (NewState)**

```
Set Visibility FightBox  = (NewState == Fighting)
Set Visibility CastBox   = (NewState == ChargingCast)
```

**ShowCatch (Species, Weight)**

```
Set Text NotificationText = "Fish caught!"
Set Visibility Visible
Delay 2.5 → Set Visibility Hidden
```

### 3. Show the widget

On `BP_FishingController` **Event BeginPlay**:

```
Create Widget (WBP_FishingHUD)
  → Add to Viewport
```

Leave `BFLHUD` assigned if you still want the Canvas fallback, or set HUD Class to `None` / a blank HUD to hide it.

## Score

`ABFLGameMode::RegisterCatch` is the only place score increases.

```
ScoreAwarded = round(WeightLbs * Species.ScorePerPound)
```

Read it anytime: `Get Score`, `Get Fish Caught`, `Get Catch Log`.
